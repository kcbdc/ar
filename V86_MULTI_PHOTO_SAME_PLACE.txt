조팸스 GO v86 - 동일 장소 다중 사진 업로드

원인
- 기존 Worker 업로드 로직은 같은 사용자 + 같은 체크포인트에 사진을 올리면
  기존 사진을 DELETE한 뒤 새 사진을 INSERT하는 '대표사진 교체' 방식이었음.

수정
- 기존 사진 DELETE 로직 완전 제거
- 업로드할 때마다 social_photos_v66에 새로운 독립 레코드를 INSERT
- 동일 사용자가 동일 장소에서 여러 번 사진 등록 가능
- 기존 사진은 유지되고 새 사진이 추가됨
- 지도 마커 배지는 v85 정책대로 해당 위치의 총 사진 개수 표시
- 본인 사진 삭제 기능과 좋아요 토글 기능 유지
- D1 스키마 변경 필요 없음

예시
동일 장소에서 같은 사용자가 1장 업로드 -> 마커 1
같은 장소에서 두 번째 사진 업로드 -> 기존 사진 유지 + 마커 2
세 번째 사진 업로드 -> 기존 2장 유지 + 마커 3

필수 재배포
- server/worker.js
- checkpoints.html
- sw.js

핵심 변경은 server/worker.js입니다.
