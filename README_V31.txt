조팸스 GO v31 — GPS 연동 실시간 날씨

- AR 카메라는 기존처럼 가장 먼저 실행되고 GPS/날씨 조회는 백그라운드 수행
- GPS 수신 후 해당 위도·경도를 Open-Meteo에 전달하여 현재 날씨/주야 상태 표시
- 날씨 HUD: 현재 위치 · 주간/야간 · 맑음/구름/비
- 1km 이상 이동하거나 10분 이상 경과 시 날씨 자동 재조회
- 네트워크 실패 시 가까운 GPS 날씨 캐시를 사용하고, 캐시도 없을 때만 대전광역시 fallback
- GPS 정확도 150m 이하의 위치만 날씨 좌표로 사용
- 서비스워커 캐시 v31로 갱신
