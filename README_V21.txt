조팸스 GO v21 — 위치 신호 안정화

- AR 위치 초기화: 빠른 coarse fix + 정밀 GPS를 병렬 요청
- 정밀 watchPosition + fallback watchPosition 이중 추적
- 최근 GPS 샘플 정확도 가중 평균으로 위치 튐 완화
- 10초 이상 위치 갱신이 없으면 자동 재요청
- GPS 정확도에 따라 탐지/포획 반경과 방향 허용폭을 자동 보정
- GPS 오차가 큰 순간이동을 스푸핑으로 오탐하지 않도록 판정 개선
- 지도 화면에도 동일한 위치 안정화/재연결 로직 적용
- 화면 종료 시 GPS watch 정리
