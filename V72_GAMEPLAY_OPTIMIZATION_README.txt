[실패 시 다른 곳으로 이동]
- 실제 미니게임 실패 시 현재 체크포인트 30분 '신호 붕괴' 잠금
- 같은 자리에서 무한 재도전 불가
- 다음 검색부터 잠긴 지점을 제외하고 다른 획득 가능 체크포인트 자동 안내
- 기존 cpCooldowns 형식을 재사용하므로 Worker/D1 스키마 변경 없음
- 소셜 로그인 계정은 기존 game-state 동기화 경로로 실패 잠금도 동기화
- 다임의 실드 1회 보호 스킬은 유지

[성능 최적화]
기존 병목
- AR 화면에서 약 120ms마다 283개 체크포인트 탐색
- 각 체크포인트마다 JopamsState clone + 공간 쿨다운 prune을 반복

개선
- cooldownSnapshot() 900ms 메모리 캐시
- nearest 탐색 1회당 쿨다운 데이터 1회만 읽음
- CHECKPOINTS.find() 대신 idx 직접 접근
- 수집상태 확인 Array.includes 반복 대신 Set 사용
- 서버 상태 적용/획득/실패 잠금 시 캐시 즉시 무효화
- 기존 GPS 판정, 100m~12m 내비게이션, 12m 이내 AR, 3일/12m 획득 쿨다운 유지

[전반 버그 점검]

- 모든 HTML inline JS 문법 검사

- HTML local script/link/img 참조 파일 존재 검사
