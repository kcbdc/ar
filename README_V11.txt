조팸스 GO v11 수정사항

1. 모든 일반 화면의 뒤로가기 버튼을 동일한 라인형 왼쪽 화살표 SVG 아이콘으로 통일
2. 홈의 'AR 탐험 시작' 버튼 하단 목표 문구를 흰색/고대비로 변경
3. 조팸스 원정대 캐릭터 스킬 문구가 글자 단위로 쪼개지지 않도록 word-break: keep-all 적용
4. 컬렉션 'N개의 제도를 발견했어요' 문구가 단어 내부에서 끊기지 않도록 수정
5. 컬렉션 원형 진행표시의 발견 숫자와 /12를 원 내부 안전영역으로 재배치
6. v10의 카드 내부 안전여백, 숫자 천 단위 구분, 딥 네이비 UI 유지
7. 업적/본부 대항전 화면 하단 메뉴를 홈·탐험·지도·컬렉션·랭킹 5개 표준 메뉴로 통일
8. Service Worker cache key를 jopams-go-v11로 갱신
